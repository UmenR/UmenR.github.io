My Journey with Linux and Open Source

My first Linux was Ubuntu 12.04 running off a USB stick on a borrowed laptop. I was hooked within an hour.

The Distro-Hopping Phase

I cycled through Fedora, Mint, Debian, and openSUSE. Each taught me something new about package management, kernel modules, and system configuration.

Settling on Arch

Eventually I landed on Arch Linux. The DIY installation process forced me to understand every component of my system. The AUR gave me access to packages I could not find anywhere else.

Open Source Contributions

Linux opened the door to open source. My first contribution was a typo fix in a documentation file. It was merged. I was over the moon.

Since then I have contributed to several projects, filed bug reports, and maintained a few small utilities.

The Philosophy

Open source is not just about free software. It is about collaboration, transparency, and building things together that no single person could build alone.

  $ git commit -m "make the world slightly better"
  [main 1a2b3c4] make the world slightly better

Linux is not just my operating system. It is my community.
